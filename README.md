# Statistics Kaggle Competition Project

Older statistics and Kaggle-style analysis project focused on applied modeling and R-based reporting.

## Portfolio Context

This repository is a coursework/archive project. It is kept public as evidence of statistical modeling practice, R Markdown reporting, and Kaggle-style structured data analysis. It is not intended to be the main portfolio proof for current data science roles.

## Repository Contents

- `Kaggle_Comp_Stats.Rmd`: R Markdown analysis report
- `house-prices-advanced-regression-techniques-2/`: Kaggle house-prices project data/workflow folder

## Skills Demonstrated

- R Markdown reporting
- statistical modeling workflow
- structured tabular data analysis
- Kaggle-style predictive modeling
- exploratory data analysis
